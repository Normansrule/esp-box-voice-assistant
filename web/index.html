On the chipESP-SR WakeNet + MultiNet. The wake word and every offline phrase are recognised on the ESP32-S3. No network, no delay, no cost. The mute switch stops capture at the microphone driver.
Optional, off by defaultOnline brain. Unrecognised questions can go to OpenAI for speech-to-text, an answer and a voice. It needs Wi-Fi, your own API key, and a switch you turn on. An hourly limit caps the bill.

Build your own

Get the hardware.
Flash the face.

Everything on this page runs on one off-the-shelf Espressif kit. No soldering, no custom board.

  1. Buy a BOX-3. The full kit if you want the temperature readout and the “someone sat down” radar; the bare 3B otherwise.
  2. Install ESP-IDF v5.5.x. Not v6. The Windows offline installer is the easy path.
  3. Build and flash. idf.py set-target esp32s3, idf.py build, idf.py -p PORT flash. Say “Hi E.S.P.”

Store links come from Espressif's own list of official sellers on the ESP32-S3-BOX-3 product page. Prices and stock change; check the store. The 18650 slot on BOX-3-SENSOR is Espressif's design; this firmware does not measure the battery yet, so use a protected cell and follow Espressif's charging instructions.

Build it

Four commands.

From an ESP-IDF 5.5 CMD window. Not v6: it removed the I2C driver the sensor dock uses.

:: cmd.exe, ESP-IDF v5.5.x environment loaded
> git clone https://github.com/Normansrule/esp-box-voice-assistant
> cd esp-box-voice-assistant
> idf.py set-target esp32s3
> idf.py build
> idf.py -p %ESP_PORT% flash monitor
