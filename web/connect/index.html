Open this page in desktop Chrome or Edge (version 89 or newer), or use the Desk Buddy Connect desktop app. Firefox and Safari do not support Web Serial, and neither do phones.

Plug in your box. Flash, watch, talk.

Everything happens between this page and the USB cable. Nothing is uploaded, and the firmware files never leave your computer once they are downloaded.

  1. Plug the ESP32-S3-BOX-3 into this computer with a USB-C data cable.
  2. Press Connect box and pick the port named USB JTAG/serial debug unit.
  3. Install firmware, open the monitor, or use the controls.

1 · Choose firmware

Select the images from your build/ folder. Add flasher_args.json too and its offsets are used; otherwise the v3.7.1 layout from partitions.csv is assumed.

A storage.bin you built yourself contains spiffs/openai_key.txt if that file existed when you built it. That is fine for your own box; do not share the image.

2 · Write it

The box restarts by itself when the write finishes, and the monitor opens so you can watch it boot. If connecting fails, hold BOOT, tap RESET, release BOOT, then try again.

Going back to the factory demo

Espressif publishes the stock ESP-BOX-3 firmware. Download its merged image, choose Files from my own build, pick that single file and it is written at offset 0x0. Or run esptool.py --chip esp32s3 write_flash 0x0 <file>.

Controls need firmware with the serial console (added after v3.7.1). Connect the box; if nothing appears here, install the latest firmware first.
